# Templates FastReport (.fr3)

Esta pasta é onde `FastReportService` espera encontrar os templates:

- `DANFeNFCe.fr3` — DANFE simplificado da NFC-e
- `DAV.fr3` — Documento Auxiliar de Venda (quando não há emissão fiscal)
- `Venda.fr3` — comprovante de venda / cupom não fiscal

Não incluí os `.fr3` de verdade porque são arquivos binários feitos no
**FastReport Designer** (ferramenta visual da própria FastReport) — não
tem como gerar um `.fr3` funcional escrevendo texto. Assim que você tiver
o pacote FastReport instalado, desenha os relatórios lá e salva com esses
nomes exatos aqui.
